# 基于 RAG 架构的企业级私有知识库智能问答系统

## 项目简介
面向企业数码产品客服场景，设计并实现端到端 RAG 智能问答系统，解决传统问答无法读取私有资料、大模型幻觉编造、检索精度低的问题。

## 技术栈
- Python + LangChain + Chroma + BGE-Small-ZH + DeepSeek-R1

## 核心工作
1. **全链路架构**：基于 LangChain 构建 RAG pipeline，支持 PDF/DOCX/TXT 多格式文档解析、语义分块、向量化存储
2. **检索优化**：采用 MMR 算法平衡相似度与多样性，新增知识命中率提升 30%
3. **幻觉抑制**：设计分层 Prompt 模板，定义相关性判断标准和固定拒答格式，干扰题拒答率 80%
4. **评测体系**：自建 440 条标注测试集（准确/模糊/干扰三类场景），自动化统计召回率、拒答率、响应耗时

## 项目成果
- 自建 **440条** 标注测试集（准确/模糊/干扰三类场景）
- 准确/模糊问答召回率 **100%**，干扰题拒答率 **80%**
- 平均响应时间 **3.5秒**
- 评测效率从人工 2 小时 → 自动 5 分钟，提升 **96%**

## 快速开始

### 安装依赖
```bash
pip install -r requirements.txt
```

### 构建知识库索引
```bash
python build_index.py
```

### 启动问答
```bash
python rag_engine.py
```

### 运行评测
```bash
python rag_engine.py
# 输入 eval 回车
```
