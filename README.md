# 基于 LangChain + Chroma 的企业知识库 RAG 智能问答系统

## 📌 项目简介
本项目基于 **LangChain** 框架搭建端到端 RAG 智能问答系统，以企业数码产品知识库为数据源，实现**私有文档向量化、语义检索、大模型增强问答、幻觉抑制、自动化评测**。
解决传统问答无法读取私有资料、大模型幻觉编造、检索精度低的问题，可直接用于企业智能客服、内部知识库问答场景。

## 🛠️ 技术栈
- **开发语言**：Python
- **RAG 框架**：LangChain
- **向量数据库**：Chroma
- **嵌入模型**：BAAI/bge-small-zh-v1.5（中文高精度语义向量）
- **大模型服务**：阿里云百炼 · 通义千问 Turbo
- **检索策略**：MMR 最大边际相关性检索（兼顾相似度 + 多样性）

## 🎯 核心功能
1. **私有知识库构建**
   支持 TXT / DOCX 多格式文档解析、文本分块、语义向量化、持久化向量库。

2. **优化 MMR 语义检索**
   调优候选集参数，解决新知识无法召回、旧文档垄断检索结果的问题，大幅提升新增知识命中率。

3. **精准召回评测体系**
   自定义文件名包含匹配逻辑，修复路径匹配误差；搭建 40 条专业测试集，自动统计：
   - 业务题召回率
   - 干扰题拒答准确率
   - 检索 / LLM / 总响应耗时

4. **大模型幻觉抑制**
   通过 Prompt 工程严格约束模型，仅依据检索内容作答，无资料自动拒答，**零编造幻觉**。

5. **双模式交互**
   - 单次交互式问答
   - 批量自动化评测
