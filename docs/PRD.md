# 产品需求文档（PRD）

## 项目名称
RAG 企业私有知识库智能问答系统

## 背景
企业数码产品客服团队每天处理大量重复咨询，人工回复效率低、成本高。需要一套智能问答系统，能自动从企业私有文档中检索答案并回复用户。

## 目标用户
- 企业客服人员（内部使用）
- 终端消费者（通过 Web/API 访问）

## 核心功能
| 功能 | 说明 |
|------|------|
| 文档管理 | 支持 PDF/DOCX/TXT 格式文档上传和解析 |
| 索引构建 | 自动将文档分块、向量化、存入向量数据库 |
| 智能问答 | 用户提问后检索相关文档，基于文档生成回答 |
| 幻觉抑制 | 无相关内容时拒绝回答，不编造答案 |
| 批量评测 | 自动化测试系统准确率和响应时间 |

## 边界情况
| 场景 | 处理方式 |
|------|----------|
| 文档无相关内容 | 回答"暂无相关信息，请联系人工客服" |
| 问题模糊 | 尝试检索最相关的文档块回答 |
| 系统未就绪 | 返回 503 状态码 |
| 问题为空 | 返回 400 状态码 |

## 非功能需求
| 指标 | 目标值 |
|------|--------|
| 平均响应时间 | < 5 秒 |
| 检索耗时 | < 100 毫秒 |
| 干扰题拒答率 | > 80% |
| 准确题召回率 | > 95% |
| 服务可用率 | > 99% |

## 优先级
| 优先级 | 功能 |
|--------|------|
| P0 | 文档解析、向量检索、智能问答、幻觉抑制 |
| P1 | Web API、批量评测、日志监控 |
| P2 | 索引重建接口、调用统计 |
