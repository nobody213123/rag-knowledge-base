# 技术难点与解决方案

## 1. 幻觉问题（Hallucination）

### 难点描述
LLM 在回答时可能"编造"知识库中不存在的内容，导致用户获得错误信息。

### 解决方案
- **强制引用指令**：System Prompt 中明确要求"只使用参考资料中的内容回答"
- **拒答机制**：当参考资料无相关内容时，要求 LLM 回答"暂无相关信息，请联系人工客服"
- **温度控制**：`temperature=0.3` 降低随机性，减少编造概率

### 评测验证
通过 440 条测试集中的 110 道干扰题验证拒答准确率，当前达到 **91%**。

---

## 2. 检索结果重复

### 难点描述
语义相似的文档片段可能被重复检索，浪费 LLM 的上下文窗口。

### 解决方案
- **MMR 检索**（Maximal Marginal Relevance）：在相似度和多样性之间取平衡
  - `lambda_mult=0.7`：0.7 偏向相似度，0.5 偏向多样性
  - `fetch_k=20`：先检索 20 条，再筛选出 10 条去重后的结果

### 评测验证
实验表明 `lambda_mult=0.7` 在准确率和多样性之间取得最佳平衡。

---

## 3. 分块边界问题

### 难点描述
文档被切分时，关键信息可能被截断在两个 chunk 的边界处，导致检索时信息不完整。

### 解决方案
- **Overlap 重叠**：`chunk_overlap=50`，相邻 chunk 有 50 字符重叠
- **实验调优**：通过对比实验确定 `chunk_size=200, overlap=50` 为最优参数

### 评测验证
| chunk_size | overlap | 准确题召回率 |
|------------|---------|-------------|
| 200        | 50      | **83.67%**  |
| 300        | 100     | 74.29%      |
| 500        | 100     | 71.43%      |

---

## 4. 中文分词与 Embedding 质量

### 难点描述
中文文档的语义理解依赖高质量的 Embedding 模型，普通模型对专业术语支持差。

### 解决方案
- **选用 BGE-small-zh**：专门为中文优化的 Embedding 模型
- **归一化**：`normalize_embeddings=True`，确保向量在同一尺度上

---

## 5. 多轮对话上下文管理

### 难点描述
多轮对话时，历史信息过多会导致 LLM 上下文溢出或混淆。

### 解决方案
- **历史窗口**：保留最近 3 轮对话历史
- **历史截断**：超过 `MAX_HISTORY_LENGTH * 2` 条时自动截断
- **可选历史**：`/chat` 接口支持 `use_history=false` 跳过历史

---

## 6. 文档溯源准确性

### 难点描述
LLM 可能在回答中引用错误的文档编号。

### 解决方案
- **Prompt 约束**：要求 LLM 在引用处加 `[数字]` 标记
- **元数据保留**：每个 chunk 保留 `source` 字段，溯源时直接从元数据读取
- **前端映射**：`溯源信息` 列表将 `[1]` 映射到具体文件名
